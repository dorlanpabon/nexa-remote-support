Your TV, within reach.

Pair and control supported Android TV and Google TV devices from your iPhone over the same Wi-Fi network. No account or cloud relay is required.

Open a support request Read the privacy policy

TV not found

Confirm both devices use the same Wi-Fi network, allow Local Network access in iPhone Settings, and start a new scan.

Pairing fails

Keep the code visible on the TV, enter all six characters, and retry while both devices remain awake.

Connection lost

Wake the TV, then reconnect from Saved TVs. Some TVs disable network access while fully powered off.
